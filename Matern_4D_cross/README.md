# 4D Matérn LQEI cross-validation

This upload folder contains the code and fixed inputs for the registered factorial
experiment on the four-dimensional Matérn-5/2 RKHS test function. Raw
trajectories and generated analysis are excluded and will be created when the
experiment runs.

## Design

The experiment uses `T=e^10.5=36,316` and `T=e^11.5=98,716`, 100 macro
replications per trajectory configuration, 20 initial points, the fixed
8,192-point Sobol candidate pool, fixed response-GP hyperparameters, and fresh
phase-code-1008 random streams.

It crosses three EI incumbents:

- `min_x(mu_n - 0.2*Lambda_n*sigma_n)`;
- `min_x(mu_n)`;
- `min_x(mu_n + sigma_n)`.

It crosses four same-rho replication-number orders:

- `O(1)`;
- `O(log log T)`;
- `O(log T)`;
- `O(T^(1/2))`.

Every saved terminal posterior is then scored over sampled points by three
final recommendation rules:

- `mu_N + 0.2*Lambda_N*sigma_N`;
- `mu_N`;
- `mu_N - 0.2*Lambda_N*sigma_N`.

Consequently, the study simulates 24 trajectory configurations and reports 72
factorial combinations. The pre-registered target combines the first incumbent,
`O(log T)`, and the positive terminal uncertainty correction.

## Run and resume

```powershell
python run_cross_validation.py all --workers 8
```

The run is resumable. Existing macro files are validated and reused unless
`--overwrite` is supplied. Other useful commands are:

```powershell
python run_cross_validation.py status
python run_cross_validation.py run --workers 8
python run_cross_validation.py analyze
python -m pytest -q tests
```

`run_cross_validation.py` is the main entry point. `experiment_runner.py`
implements the trajectories; `study_config.py`, `confidence.py`,
`sequential_gp.py`, and `rkhs_functions.py` define the experiment and model.
`analyze_cross_validation.py` produces the analysis after all trajectories finish.
Keep `fixed_functions/`, `shared_inputs/`, and `confidence_schedules/` with the
code. The confidence schedules are small precomputed inputs and can also be
regenerated by the runner. The full run involves 2,400 trajectories and may
take substantial time.

## Outputs

Raw trajectories are written below `results/cross_validation_trajectories`.
The analysis writes:

- `analysis/combination_summary.csv` with mean GAP, bootstrap 95% CI, and
  median `[Q1, Q3]` for all 72 cells;
- `analysis/all_macro_results.csv` with all 7,200 recommendations;
- `analysis/target_pairwise_comparisons.csv` with paired target-versus-
  competitor comparisons;
- `analysis/REPORT.md` and figures;
- `analysis/validation_report.json` and root-level `suite_completion.json`.

These outputs, including `suite_completion.json`, are intentionally absent from
this upload folder. The final-rule factor is paired postprocessing and does not
create additional simulation trajectories.
